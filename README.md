# Validador de E-mail com JavaScript

Projeto simples que valida e-mail digitado pelo usuário com regras claras e feedback visual.

**Tecnologias:** HTML5, CSS3, JavaScript (Regex, manipulação DOM)

**O que validei:**
- Precisa ter @ e .
- Texto antes e depois do @
- Domínio válido (ex: .com)
- Mensagens de erro/sucesso

🔗 Demonstração: rode o index.html no navegador
